# Documentation assets

`demo-underwater-source.jpg` is synthetic demo media created for AquaRecover's
documentation on September 16, 2026. It is not a photograph from the private
`test/img` collection and does not depict a real person. It exists so the
simulator workflow and public screenshots can be reproduced without
redistributing a contributor's dive media.

`editor-split.webp`, `editor-crop.webp`, and `export-review.webp` are captures
of the real iOS Simulator build using that source image. They are not interface
mockups.

The demo image is intentionally not an algorithm reference. It must not be used
to draw conclusions about restoration quality or performance.
