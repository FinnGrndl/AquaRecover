# Support

Use GitHub Issues for reproducible bugs and focused feature requests. Search
existing issues first and include the AquaRecover version, operating-system
version, device, media type, and steps to reproduce.

Do not upload a private photo or video just to demonstrate a problem. A cropped
or synthetic sample is usually enough. Security reports belong in the private
channel described in `SECURITY.md`.

This is a volunteer open-source project. There is no guaranteed response time
or individual support agreement.
